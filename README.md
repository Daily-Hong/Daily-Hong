# Jonghun Hong

**CEO [@Oraclizer](https://github.com/Oraclizer)** — regulated tokenization infrastructure.

Oraclizer builds the state-synchronization layer between institutional ledgers and EVM execution, so that a regulated asset means the same thing on both sides: same rights, same restrictions, same enforcement, provably.

### What we work on

- **[ERC-TRUST](https://github.com/Oraclizer/erc-trust)** — typed regulatory actions for security tokens (`FREEZE` · `SEIZE` · `CONFISCATE` · `LIQUIDATE` · `RESTRICT` · `RECOVER`), each bound to authority, evidence, replay-prevention, and a receipt an independent observer can recompute. Verified with Isabelle/HOL, Certora, Kontrol/KEVM, and Foundry.
- **ERC-8319 (RCP)** — the Regulatory Compliance Protocol the typed actions build on.
- **OSS state synchronization** — Canton ↔ EVM, bidirectional, with finality confirmation and mismatch recovery.
- **Formal verification as a product requirement**, not a paper exercise: theorems traced to executing code and tests.
